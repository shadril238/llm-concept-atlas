A visitor asks about a changing community library collection. The product should find the right policy, answer the actual question, and make every factual claim inspectable. This original project follows Chapter 8 with **24 fictional source documents and real local models**. It connects search quality to answer correctness without assuming that a plausible answer is grounded.

## 1. Establish a baseline

Follow [L12 setup](/llm-concept-atlas/labs/retrieval-and-multimodal/#set-up-and-choose-a-profile), then run `retrieval-benchmark`. Preserve document/chunk IDs, original offsets, preprocessing, encoder revision, index parameters and all rankings. Six design questions select the abstention threshold; sixteen separate evaluation questions measure ranking. Compare BM25, dense retrieval and candidate-limited reranking using P@k, AP/MAP and graded nDCG. Report absent-answer cases separately. Do not tune on the displayed evaluation results and then call them unseen.

## 2. Run the actual grounded workflow

Run `grounded-retrieval` after its first model download. The [complete L13 source](/llm-concept-atlas/labs/retrieval-and-multimodal/#l13-grounded-retrieval) performs actual local generation across six strategies. Context includes source IDs and whole passages under a token budget. Inspect the generated query, every search, dropped passage, actual prompt, raw answer, and controller decision.

<GroundedExplorer client:visible />

The correct Saturday closing time is **17:30**, the laptop period is three days, and the book period is twenty-one days. A model can return a true number from the wrong entity. The Aurora task needs Aurora → Wren → Birch → 42; a detour through Lark/Aspen returns 57. Missing pool hours and parking prices test whether the system can avoid inventing an answer. No simulated fixed answer is presented as model output.

## 3. Review support before displaying citations

<CitationAuditor client:visible />

Split a draft into checkable propositions. Grade answer correctness against the question, faithfulness against supplied context, and each citation against its associated proposition. Multiple partial sources may jointly support a multi-hop claim. Missing citations reduce recall; an unrelated citation reduces precision. Uncertain support requires review. The author reviewed all 48 raw drafts separately from the threshold-based display override; independent review is pending.

## 4. Deliver an inspectable prototype

A useful interface shows the answer, relevant source excerpts, source IDs, and an honest “not enough evidence” state. Store versioned evidence and review results alongside each evaluated run. Retrieved documents remain data even if one says to ignore the user's instructions. The threshold guard is one policy layer, not proof of robust instruction isolation or factual correctness.

**Acceptance exercise:** Explain one retrieval failure, one context-budget failure mode, one wrong-entity answer, and one absent-answer hallucination using actual traces. Propose a change, predict its effect, and evaluate on fresh questions. Choose search alone if readers only need a page; choose a structured database query if the source is already a small authoritative table.

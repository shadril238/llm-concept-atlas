## 1. Understand the representation

Read [text embeddings](/llm-concept-atlas/concepts/text-embedding/), [semantic search](/llm-concept-atlas/concepts/semantic-search/) and [dense retrieval](/llm-concept-atlas/concepts/dense-retrieval/). Predict the difference between a lexical match and a learned paraphrase match. Inspect the actual 384-dimensional query and dot products. A similarity score orders candidates; it does not establish answer support.

## 2. Preserve and rank evidence

Read [chunking](/llm-concept-atlas/concepts/document-chunking/), [reranking](/llm-concept-atlas/concepts/reranking/), and [retrieval metrics](/llm-concept-atlas/concepts/retrieval-metrics/). Experiment with source boundaries, overlap, unique-document collapse, AP denominators and graded nDCG. Then run [L12](/llm-concept-atlas/labs/retrieval-and-multimodal/#l12-retrieval-benchmark).

**Checkpoint:** Can a cross-encoder recover a source outside its candidate set? Explain the candidate ceiling using a saved ranking. Why does an absent-answer query have undefined AP?

## 3. Build the answer stage

Read [RAG](/llm-concept-atlas/concepts/rag/), [grounded generation](/llm-concept-atlas/concepts/grounded-generation/) and [local-model RAG](/llm-concept-atlas/concepts/local-model-rag/). Run [L13](/llm-concept-atlas/labs/retrieval-and-multimodal/#l13-grounded-retrieval). Follow actual context selection into the generator prompt and distinguish raw text from a controller-withheld display.

**Checkpoint:** The model says twenty-one days for a laptop because the supplied source discusses books. Which stage introduced the wrong entity? Does fluency change that diagnosis?

## 4. Verify every proposition

Read [RAG evaluation](/llm-concept-atlas/concepts/rag-evaluation/). Compare correctness, faithfulness, utility, fluency, citation precision and joint-set citation recall. In the auditor, cite both the room-to-wing and wing-to-code sources for a chained claim. A source ID resolving successfully is weaker than semantic entailment.

## 5. Compare advanced strategies

Follow [rewriting](/llm-concept-atlas/concepts/query-rewriting/), [multi-query](/llm-concept-atlas/concepts/multi-query-rag/), [multi-hop](/llm-concept-atlas/concepts/multi-hop-rag/), [routing](/llm-concept-atlas/concepts/query-routing/) and [agentic RAG](/llm-concept-atlas/concepts/agentic-rag/). Inspect real planning calls and work counts. Explain a lost entity, irrelevant route, repeated source, and stop budget. These are small mechanism probes; extra calls do not guarantee improvement.

## 6. Transfer to a project

Complete the [grounded document assistant](/llm-concept-atlas/use-cases/rag-question-answering/). Use a new licensed collection and fresh queries before making a new quality claim. Retrieval training/adaptation is a later Chapter 10 exercise; inference and evaluation alone do not train the encoder. Optional hosted execution remains a documented/imported comparison.

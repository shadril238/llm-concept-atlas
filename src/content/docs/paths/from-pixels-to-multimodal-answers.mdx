## 1. Make the model input visible

Read [multimodal preprocessing](/llm-concept-atlas/concepts/multimodal-preprocessing/). Compare source dimensions, resize, crop, normalization, tensor layout and text IDs. Predict what information is permanently removed. Then read [vision transformers](/llm-concept-atlas/concepts/vision-transformers/) and inspect a real patch projection.

## 2. Compare image and text

Read [multimodal embeddings](/llm-concept-atlas/concepts/multimodal-embeddings/), [CLIP](/llm-concept-atlas/concepts/clip/) and [OpenCLIP](/llm-concept-atlas/concepts/openclip/). Use the [L14 retrieval explorer](/llm-concept-atlas/labs/retrieval-and-multimodal/#l14-openclip-retrieval). Explain unit-vector similarity, paired contrastive loss, and candidate-dependent softmax using saved actual numbers. Equal vector widths are necessary for a dot product, but training is what makes those representations compatible.

## 3. Bridge vision into language

Read [BLIP-2](/llm-concept-atlas/concepts/blip-2/), [Q-Former](/llm-concept-atlas/concepts/q-former/) and [image captioning](/llm-concept-atlas/concepts/image-captioning/). Inspect actual hooked tensor shapes in the separately verified heavy Linux run. Explain why 32 learned queries are not 32 image patches, and why the projection changes width. Distinguish historical pretraining from this inference-only experiment.

## 4. Follow a real visual conversation

Read [multimodal chat](/llm-concept-atlas/concepts/multimodal-chat/). Inspect both image-processing conditions, generated first-turn history, second prompt, and continuation-only output. The price is absent from the picture. Explain why one condition's confident “100” is unsupported and why the second-turn comparison includes mediated history changes.

Complete the [image/text search project](/llm-concept-atlas/use-cases/image-text-collection-search/). Deliver visible provenance and source/model-input comparisons. Use fresh licensed images and frozen relevance judgments for new quality claims.

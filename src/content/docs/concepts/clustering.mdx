## Definition and intuition

Text clustering fits groups from feature geometry without target class labels. HDBSCAN uses density structure and can mark points as noise; its group IDs are local identifiers, not predefined semantic classes.

Clustering is useful when you do not yet have a trustworthy taxonomy. It cannot decide by itself whether a group is meaningful for a reader or useful for a product. The chosen representation and density assumptions determine what can become a group.

## How it works

### Density rather than fixed class centers

HDBSCAN builds and condenses a hierarchy based on density-related distances, then selects stable groups under a specified selection rule. min_cluster_size sets a minimum retained group size; min_samples changes how conservatively density is assessed. The result may contain −1 points that do not satisfy the grouping criterion. −1 is not a new coherent semantic topic and does not mean the document is useless.

### The actual fitted experiment

L08 clusters a real UMAP reduction of pretrained document vectors. Its baseline uses min_cluster_size 5, min_samples 8, Euclidean distance in the five-dimensional reduction, and excess-of-mass selection. It finds three topics and one noise document in this recorded run. The control experiment changes only min_samples to 3 on exactly those same points. The bridge document about speech, translation, and summaries joins a group under the less conservative setting.

### Compare membership, not names

A rerun can call the same groups 0,1,2 in a different order. Compare a contingency table, outlier transitions, and a label-permutation-invariant partition measure such as adjusted Rand index. L08 reports ARI with all −1 points treated as a group; that convention is explicit because noise is not one semantic class. The measured value describes these two partitions only.

## Implement it

This small mechanism uses Python’s standard library and illustrative values; it does not claim to run a pretrained model. Run `python3 scripts/run-examples.py --id discovery-clustering`. The connected workflow below supplies the actual model, data, and evaluation.

{/* example:discovery-clustering:start */}

```python
a = [0, 0, 1, 1]
b = [7, 7, 3, 3]
pairs = [(i, j) for i in range(len(a)) for j in range(i + 1, len(a))]
agreement = sum((a[i] == a[j]) == (b[i] == b[j]) for i, j in pairs) / len(pairs)
print("raw ID equality:", sum(x == y for x, y in zip(a, b)) / len(a))
print("pair agreement:", agreement)
assert agreement == 1
```

## When to use it

Use clustering to explore a collection, support manual labeling, or identify groups needing separate review. Inspect small groups, borderline documents, and outliers, then test whether the resulting organization serves the intended use case.

## Limits and common mistakes

Density groups in a distorted reduction are not objective categories. The curated corpus includes unrelated texts that can still be absorbed into a plausible-looking group. Do not present membership strength as probability that the topic meaning is correct.

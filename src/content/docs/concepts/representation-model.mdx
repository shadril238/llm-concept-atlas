## Picture it

Instead of writing a reply, the model reads “The film was delightful” and returns a vector or a sentiment label. The output describes the input in a form another system can use.

## Why it matters

Many language tasks need a good representation, not generated prose. Classification, clustering, and retrieval often start here.

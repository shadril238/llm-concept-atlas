## Definition and intuition

An encoder-only transformer computes contextual representations of an available input, usually allowing each nonpadding position to attend to both earlier and later positions. A task head can then classify tokens, sentences, or other structures.

In “The bank approved the loan,” the word after “bank” helps identify its meaning. An encoder can incorporate both sides of the complete input instead of being restricted to the already-seen prefix.

## How it works

Bidirectional attention concerns which input positions are visible in a forward pass. It does not mean the model knows unseen documents. A padding mask can still exclude filler positions, and other task-specific masks may impose additional restrictions.

BERT-style masked-language pretraining hides selected token identities and predicts them from context. This differs from causal next-token prediction. The [MASK] symbol is a training/task marker; leaving every input word visible and asking a model to copy it would not create the same learning problem.

The encoder output is a sequence of contextual states. Sequence classification, token classification, and sentence embedding all require different heads or aggregation choices. A pretrained encoder’s existence does not supply a well-trained downstream classifier automatically.

### The important distinction

Bidirectional context inside a known input is not permission to leak future labels or held-out documents into training.

## Worked example

For a three-token input, a bidirectional visibility matrix is all allowed positions, while a causal decoder’s matrix is lower triangular. At the middle position, the encoder can use the third token; the causal decoder cannot. The real representation lab checks that changing context changes a bank hidden state.

## When to use it

Choose an encoder for tasks where a complete input is already available, such as tagging, document classification, or encoding for retrieval. Compare pooling and fine-tuning choices on held-out data. The NER reference lesson shows an actual trained token-classification head.

## Limits and common mistakes

Bidirectional context inside a known input is not permission to leak future labels or held-out documents into training. An attention matrix is not a complete causal explanation of the model’s decision. A model’s uncased tokenizer may remove capitalization useful for names.

## Definition and intuition

Self-attention derives queries, keys, and values from the same available sequence, allowing each permitted position to combine information from other positions in that sequence.

A word’s useful representation depends on nearby and distant context. A model should combine information from several positions without reducing the whole input to one fixed state before every output is computed.

## How it works

Given X [T,d_model], learned projections produce Q=XWq, K=XWk, and V=XWv. Projection matrices differ, even though their source X is shared. Self-attention is therefore not simply comparing a vector with an identical copy of itself.

An encoder can allow bidirectional visibility. A causal decoder uses a lower-triangular pattern so position i cannot consume a future position j>i. A position’s current input token is visible while its output predicts the next token; this is not leakage of the unknown next token.

Multiple heads project into different learned subspaces, attend separately, concatenate their value mixtures, and apply an output projection. Head number is an architecture setting, not a guarantee that each head corresponds to one human-readable linguistic role.

### The important distinction

A triangular image drawn after the computation does not prove a causal implementation.

## Worked example

For three positions, the causal allowed rows are [1,0,0], [1,1,0], and [1,1,1]. The first output must not change when a future value changes. L05 tests future-value exclusion and compares masked attention with a tensor-library reference.

## When to use it

Use self-attention to contextualize a sequence under a declared visibility policy. Inspect the matrix shape and mask before treating encoder and decoder computations as equivalent. The browser experiment lets you select a query row and toggle the causal constraint.

## Limits and common mistakes

A triangular image drawn after the computation does not prove a causal implementation. Test future influence numerically. Attention scores alone do not explain the entire network, and a visible self-edge does not mean a model is copying the answer token.

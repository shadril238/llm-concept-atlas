## Definition and intuition

A bag-of-words representation counts vocabulary items in a document and stores the counts in a fixed coordinate order. It preserves which items occur and how often, while discarding their order.

You need a cheap baseline for sorting short support tickets. Counting terms can expose useful topic signals without downloading a transformer. The baseline is especially informative because its limitations are easy to inspect.

## How it works

Build a vocabulary from the permitted training corpus, assign one coordinate per item, tokenize each document consistently, then count occurrences. A document vector has shape [vocabulary_size], regardless of document length. Most coordinates are zero in a large vocabulary, so sparse storage is natural.

Vocabulary order is part of the model contract. If training uses [cat, dog, bites] and inference swaps the first two coordinates, the classifier receives a different meaning without any shape error. Store the vocabulary with the fitted model.

Counts are not probabilities or learned semantic coordinates. TF-IDF can reweight counts using corpus statistics, but it still does not restore word order. A downstream classifier may learn label weights for these features; the count vectorizer itself is a separate transformation. Fit vocabulary and weighting statistics on training data only.

### The important distinction

A vocabulary fitted on all data leaks information about held-out inputs.

## Worked example

“dog bites cat” and “cat bites dog” both become [1, 1, 1] under vocabulary [cat, dog, bites]. The representation therefore cannot distinguish who bit whom. “dog dog” becomes [0, 2, 0], so frequency survives even though order does not.

## Implement it

Run the small mechanism from the repository root with `python3 scripts/run-examples.py --id foundation-bag-of-words`. Its values are illustrative; it isolates the stated operation rather than pretending to load a trained model.

{/* example:foundation-bag-of-words:start */}

```python
vocabulary = ["cat", "dog", "bites"]
for sentence in ["dog bites cat", "cat bites dog", "dog dog"]:
    words = sentence.split()
    print(sentence, [words.count(term) for term in vocabulary])
```

## When to use it

Use counts or TF-IDF as a baseline when exact terms are informative and compute is limited. Compare against embeddings on the same held-out cases. Inspect negation, spelling variation, rare terms, and a domain shift rather than assuming a larger model always earns its additional cost.

## Limits and common mistakes

A vocabulary fitted on all data leaks information about held-out inputs. A dense array filled with zeros wastes memory but is not a dense learned embedding. A high label score does not establish that the representation understands syntax or synonyms.

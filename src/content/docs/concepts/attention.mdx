## Definition and intuition

**Attention** is a weighted combination of information from available positions. For one target position, a query scores keys from other positions; normalized scores become weights; the weights combine value vectors. It is a computation that helps tokens exchange context, not a literal spotlight revealing the model’s full reasoning.

A heatmap can show the weights for one head and one layer, but another head or layer may use a different pattern.

## Before you start

Read [transformer](/llm-concept-atlas/concepts/transformer/) first; return here when the key terms feel familiar.

## How it works

For target position `i`, compute a score against each allowed key `j`: `score(i,j) = q_i · k_j / √d`, where `d` is key width. Apply a mask to disallowed positions, then softmax across the remaining scores to obtain weights summing to one. The output is `Σ_j weight(i,j) × v_j`. Learned projections produce queries, keys, and values from hidden states.

Scaling by `√d` keeps dot products from becoming too large as vector width grows. Multi-head attention repeats this calculation with different learned projections and combines the results. Causal attention masks future positions; encoder attention commonly allows the full input.

## Worked example

Suppose a query has two available scores, `2` and `1`. Softmax gives about `0.73` and `0.27`. If their scalar values are `10` and `0`, the weighted output is about `7.3`. The higher-scored position contributes more, but the lower one still contributes.

## Implement it

**Setup:** Python 3; no packages or API key needed. Save this as `example.py` and run `python3 example.py`. This is a small teaching model, not a pretrained neural network.

```python
from math import exp
scores = [2.0, 1.0]
weights = [exp(x)/sum(exp(y) for y in scores) for x in scores]
values = [10.0, 0.0]
print([round(w, 2) for w in weights], round(sum(w*v for w,v in zip(weights,values)),2))
```

**Expected behavior:** Weights around `[0.73, 0.27]` and output around `7.31`.

The example uses precomputed scores to isolate softmax and weighted summation. In a transformer, the model first computes those scores from query and key vectors. Try the lab to change the target token and mask.

## When to use it

- Attention helps transformers incorporate context for translation, classification, and generation.
- Inspect weights to debug mechanics, while using stronger methods to evaluate model behavior.

## Limits and common mistakes

- A large attention weight is not proof of causal importance or correct interpretation.
- The weights are conditional on one position, head, and layer; there is no single global attention map.

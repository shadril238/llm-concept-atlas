## Definition and intuition

A transformer block combines attention, a position-wise feedforward network, residual connections, and normalization. The arrangement and activation vary by architecture, so the exact forward equations should be stated.

## How it works

In a simplified pre-normalized block, H = X + Attention(Norm(X)); Y = H + MLP(Norm(H)). Attention mixes permitted positions. The MLP applies shared parameters independently at each position. Residual additions require matching shapes.

A feedforward expansion can map d_model to a wider hidden width, apply a nonlinearity, then project back. The transparent random-weight lab uses a ReLU MLP. The book also discusses SwiGLU: SiLU(XW_gate) multiplied elementwise by XW_up, followed by W_down. This gating changes the computation and parameter shapes.

Normalization controls activation scale; it does not normalize a probability distribution. LayerNorm subtracts a coordinate mean and divides by a standard deviation. RMSNorm divides by root mean square without the same centering step. Learned affine parameters are additional model parameters; the arithmetic trace fixes them to identity.

### The important distinction

A position-wise MLP does not itself read another token, though its input may already contain contextual information.

## Worked example

For x=[1,2,3], LayerNorm without learned affine terms produces roughly [-1.225,0,1.225], while RMSNorm produces about [0.463,0.926,1.389]. Adding a zero residual branch leaves x unchanged. The two normalization results differ because only one subtracts the mean.

### Normalization and residuals

Normalization statistics are computed over the feature coordinates described by the layer, not over future labels. A residual connection provides an additive path around a transformation; its output is still processed by subsequent operations. In the common pre-norm arrangement, normalization precedes each branch. A model using post-norm instead places normalization after the addition, so the equations and gradients differ.

### Feedforward activations

ReLU returns max(0, z). SiLU returns z·sigmoid(z), and SwiGLU uses a SiLU-activated gate multiplied by a second projected branch. For gate input 0 the gate is zero; for a large positive input it approaches a roughly linear response. Do not substitute ReLU in a code example and claim it is a SwiGLU implementation.

## Implement it

Run the small mechanism from the repository root with `python3 scripts/run-examples.py --id foundation-transformer-block`. Its values are illustrative; it isolates the stated operation rather than pretending to load a trained model.

{/* example:foundation-transformer-block:start */}

```python
from math import sqrt

x = [1.0, 2.0, 3.0]
mean = sum(x) / len(x)
ln = [(v - mean) / sqrt(sum((z - mean) ** 2 for z in x) / len(x) + 1e-5) for v in x]
rms = [v / sqrt(sum(z * z for z in x) / len(x) + 1e-5) for v in x]
print("LayerNorm:", [round(v, 3) for v in ln])
print("RMSNorm:", [round(v, 3) for v in rms])
```

## When to use it

Use an explicit block trace when implementing or inspecting a model. Record pre- versus post-normalization, activation, widths, head counts, and positional scheme. A change to one block component needs task and numerical evaluation, not only a more modern label.

## Limits and common mistakes

A position-wise MLP does not itself read another token, though its input may already contain contextual information. A residual path does not prevent all training problems. FlashAttention is an implementation strategy for attention and does not define the MLP or normalization order.

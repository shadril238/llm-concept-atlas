## Definition and intuition

**Transformer block**: A transformer block combines attention with a position-wise feed-forward transformation and residual paths.

Chapter 3 traces a transformer forward pass. Distinguish the computation performed for a fixed input from the repeated loop used to generate new tokens.

## Before you start

Read [Attention](/llm-concept-atlas/concepts/attention/) first. You should be able to explain what information its output carries. Then return here and ask what extra problem **transformer block** solves. This sequence matters because a plausible output can hide a missing prerequisite or a weak input representation.

## Theory: how it works

1. **Prepare:** Normalize and project the incoming hidden states
2. **Transform:** Mix information across token positions using attention
3. **Inspect:** Apply a feed-forward transformation and add residual information.

### The important distinction

In a typical block, attention mixes across positions while the feed-forward network transforms each position independently. Residual additions let later layers refine rather than replace the incoming representation. Layer normalization stabilizes the scale of these transformations; exact ordering varies among model architectures.

## Worked example

For “The cat slept”, a middle block can let “slept” collect information about “cat”, then transform its own hidden representation. Repeating blocks builds progressively contextual features. Walk through the three stages above with that input: identify what is prepared, what changes, and which observation would show success. Then change one condition in the example. ## Implement it

**Setup:** Python 3; no packages or API key are needed. Save the following as `example.py` and run `python3 example.py`. It is a small deterministic illustration of the relevant calculation or data flow. It does not download a trained model.

```python
from math import exp
scores = [1.2, 0.4, -0.3]
weights = [exp(x) for x in scores]
weights = [x / sum(weights) for x in weights]
values = [2.0, 0.0, 1.0]
print(round(sum(w*v for w, v in zip(weights, values)), 3))
```

**Expected output:**

```text
1.329
```

**What the code shows:** Exponentiating scores and dividing by their total forms softmax weights. The final line combines the values using those weights, which is the central attention operation. The [official chapter 3 notebook](https://github.com/HandsOnLLM/Hands-On-Large-Language-Models/tree/main/chapter03) develops the corresponding model-based implementation.

## Limits and common mistakes

- The toy sequence hides multi-head attention, normalization details, and architecture variants.
- **Failure to look for:** Confusing one attention map with the entire block misses the feed-forward and residual computations.

A teaching demo usually holds data and model behavior fixed so one mechanism is visible. Real systems face noisy inputs, changing distributions, and edge cases. Test examples that should fail as well as examples that should succeed, and inspect the intermediate stage that causes the error.

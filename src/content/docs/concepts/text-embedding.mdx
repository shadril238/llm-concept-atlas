## Definition and intuition

A text embedding represents a sentence or document as a fixed-width vector for a specified task. It usually combines token-level computation with pooling or a dedicated representation head and suitable training.

A search application needs to compare millions of passages repeatedly. One vector per passage allows precomputation and efficient retrieval, but the representation must be useful for the queries and documents being compared.

## How it works

An encoder produces [batch, T, d] token states. Masked mean pooling multiplies each state by the attention mask, sums over positions, and divides by the count of nonpadding positions. This yields [batch, d]. Padding must not contribute as if it were content.

L2 normalization scales a nonzero vector to unit length. For normalized vectors, the dot product equals cosine similarity. This simplifies comparison, but does not calibrate the score as a probability of relevance or remove domain bias.

Sentence-level training determines which pairs should be close. A word-level co-occurrence objective, a masked-token objective, and a sentence-pair objective optimize different signals. A long document may exceed the encoder limit; chunking or aggregation needs an explicit policy and evaluation.

## Worked example

Suppose content vectors are [1, 0] and [0, 1], while a padded position contains [9, 9]. A mask [1, 1, 0] gives mean [0.5, 0.5]. Averaging all three positions would instead distort the result toward padding. L03 runs real mask-aware pooling and prints a sentence cosine matrix.

## Implement it

Run the small mechanism from the repository root with `python3 scripts/run-examples.py --id foundation-text-embedding`. Its values are illustrative; it isolates the stated operation rather than pretending to load a trained model.

{/* example:foundation-text-embedding:start */}

```python
states = [[1.0, 0.0], [0.0, 1.0], [9.0, 9.0]]
mask = [1, 1, 0]
pooled = [
    sum(row[d] * keep for row, keep in zip(states, mask)) / sum(mask) for d in range(2)
]
print("masked mean:", pooled)
```

## When to use it

Use text embeddings for semantic retrieval, clustering, or similarity features when the embedding model and domain are appropriate. Compare with keyword search for exact strings. Keep corpus/model revisions with stored vectors so later queries use a compatible space.

## Limits and common mistakes

A 2D plot can distort neighborhood relationships. An average over arbitrary token states is not a validated sentence model. A high cosine for “good” and “bad” can reflect shared context rather than interchangeable meaning; inspect negative examples and task-specific labels.

## Definition and intuition

Few-shot classification trains a predictor with a small labeled sample per class. It is distinct from giving demonstrations to a prompt: these experiments actually update model parameters or fit a classifier.

Follow the input, objective, update, and evaluation as separate steps. The worked example and experiment below connect the explanation to an inspectable implementation.

## How it works

### Declare the sampling unit

L18 samples eight reviews per class from the fixed training split under seeds 11, 23 and 37. Within a seed all methods receive identical selected IDs. Validation and test remain fixed. Class balance is controlled here, but rare classes and source-group dependence need explicit treatment in a real dataset.

### Use informative controls

Compare lexical TF-IDF/logistic regression, frozen sentence vectors plus logistic regression, full/partial/head-only BERT and two-stage SetFit. The frozen sentence route is the direct encoder-adaptation control for SetFit. Tiny BERT and pretrained MiniLM sentence encoders have different architectures and prior training, so their comparison does not isolate just the objective.

### Report variability and independent labels

Pair generation can create many optimization examples from sixteen labeled reviews without creating sixteen new independent labels per pair. Report results for every seed and descriptive mean, standard deviation and range. Three samples are too few for a strong population confidence statement; a single favorable seed is even weaker.

## Worked example

The same eight-positive/eight-negative budget can include different vocabulary and difficult examples under another seed. Find the largest SetFit/frozen-encoder gap and inspect its test errors. A reported average can conceal a seed where the adapted encoder underperforms its frozen counterpart.

From the repository root, install the foundation environment and run `python3 scripts/run-examples.py --id e7-few-shot-classification --offline`. Recorded-evidence replay is distinct from new optimization: the connected model lab supplies the complete source and fresh-training command.

{/* example:e7-few-shot-classification:start */}

```python
import json
from pathlib import Path
from statistics import mean, pstdev
data = json.loads(Path('src/data/training-results.json').read_text())['classification']
for method in ['setfit', 'frozen-sentence-logistic']:
    scores = [r['test']['macro_f1'] for r in data['runs'] if r['method'] == method]
    print(method, 'selections:', len(scores), 'mean:', round(mean(scores), 4), 'population SD:', round(pstdev(scores), 4))
print('Three fixed selections describe variability; they are not a confidence interval.')
```

## When to use it

Use it when annotation is expensive and a pretrained representation provides a useful starting point. Spend some label budget on validation and error review rather than reporting only a training fit.

## Limits and common mistakes

Validation sets can overwhelm a tiny training budget if their annotation cost is ignored. This experiment reuses an existing forty-review validation set, so “sixteen training labels” is not a claim that the entire project consumed only sixteen human labels.

Author execution checks tensor/mask contracts, actual parameter updates, split provenance and artifact reload. It does not constitute independent lesson acceptance. Keep training quality, task quality, runtime and generalization claims separate.

## Definition and intuition

A large language model is a language model with substantial learned capacity, commonly built from transformer layers and trained on broad text. “Large” is a relative historical description, not a fixed parameter threshold or a guarantee of capability.

A team proposes a “larger model” for document search. Before comparing parameter counts, ask whether the required output is an embedding, a label, or generated text, and what improvement would justify additional memory and latency.

## How it works

A causal language model estimates a distribution for the next token given earlier tokens. Training repeatedly adjusts parameters to make observed continuations more likely. The learned distribution captures statistical structure and can support useful tasks, but the objective is not a direct truth-verification procedure.

Parameters are stored numeric values. Hyperparameters such as temperature, context budget, and learning rate control a procedure; they are not interchangeable with learned weights. Context supplies information during a run without necessarily changing any parameter.

Parameter count, architecture, training data, objective, adaptation, and inference configuration all affect behavior. A small base model may be ideal for inspecting mechanics while producing poor instructions. Our pinned Pythia-14m example is deliberately small and is not presented as a capable assistant.

### The important distinction

More parameters do not imply a longer supported context or current factual knowledge.

## Worked example

A next-token head can output logits [2, 1, 0] for three candidate IDs. Softmax converts these to approximately [0.665, 0.245, 0.090]. Greedy decoding chooses the first ID. This local probability comparison says nothing about whether the resulting sentence is factually correct.

## When to use it

Choose a model through task evidence, hardware requirements, data-handling needs, and reproducibility. For a learning exercise, a small accessible model is often better than a model that cannot run on the declared device. For deployment, measure the real workload and error costs.

## Limits and common mistakes

More parameters do not imply a longer supported context or current factual knowledge. A model can assign high probability to a common false statement. A prompt can elicit confident prose even when the source data needed to answer is absent.

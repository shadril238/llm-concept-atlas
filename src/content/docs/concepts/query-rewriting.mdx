## Definition and intuition

Query rewriting transforms a conversational or poorly focused request into a retrieval query while preserving its intended subject and constraints. The rewritten text changes what the retriever sees; it is not itself an answer.

Read this lesson as a sequence: identify the input, follow the transformation, inspect the result, and explain a failure. The worked example and recorded lab below make those boundaries visible.

## How it works

### Recover the actual information need

A conversation can mention an abandoned option before a final choice. Searching all those words can retrieve the wrong subject. The rewriter receives the actual request and is asked for a short query preserving the final choice. Names, dates, exclusions, and referents are important invariants. A shorter query that drops a crucial qualifier is a failure, even if it sounds cleaner.

### Measure the rewrite as an intervention

L13 records the original question, actual generated rewrite, resulting search, packed passages, and final answer. It does not replace a poor rewrite with a human-crafted ideal. An empty rewrite has an explicit original-query fallback. The model can answer instead of rewriting or introduce a new entity; those strings are still visible. The comparison uses author-known mechanism probes rather than claiming untouched generalization after prototype inspection.

### Preserve the baseline

The unchanged original-question retrieval is a separate condition. Compare support-document coverage and answer behavior, not simply whether the rewrite reads well. Rewriting adds a model call and token work. The answerability threshold was selected on L12 design queries and reused; it is not recalibrated for every changed rewrite distribution. That limitation is visible when a rewrite causes withholding.

## Worked example

The animal-access request mentions a cat, then chooses an assistance dog. A faithful search query should preserve the chosen dog and permission question. A rewrite about a generic community center or an unrelated date can remove the policy evidence. Open the actual rewrite call and trace exactly which phrase altered the search results.

## When to use it

Use rewriting for verbose requests, conversational references, or domain-specific search wording when the necessary context is available. Keep a direct-query baseline and test subjects, negations, dates, and final-choice corrections.

## Limits and common mistakes

A rewriter can hallucinate a subject, answer prematurely, or lose a qualification. More concise text is not necessarily better retrieval. The atlas does not claim general intent preservation from this small model or silently repair its outputs with reference answers.

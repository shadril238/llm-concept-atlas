## Definition and intuition

Zero-shot classification assigns labels without local labeled training examples for that decision rule. Label-description similarity, entailment scoring, and generated labels are distinct mechanisms with different score meanings.

No local labels does not mean no assumptions. You supply class meanings, a prompt or hypothesis template, a candidate set, and a pretrained model. Those choices can materially change predictions without changing the input review.

## How it works

### Similarity to descriptions

L07 embeds fixed negative/positive descriptions with the same frozen MiniLM encoder as the reviews. Dot products between unit vectors are cosines. The larger similarity selects a label, but no learned local boundary or calibrated probability is created. The lab also evaluates a second predeclared wording and lists prediction flips rather than choosing the winner on the test set.

### Entailment-style scoring

An NLI model reads a premise and a hypothesis together. For each review, L07 tests negative and positive sentiment hypotheses, extracts the configured entailment logit, and normalizes those two logits across mutually exclusive candidates. It inspects the actual NLI label map rather than assuming a column number. This two-candidate normalization is different from each pair’s three-way contradiction/entailment/neutral probabilities.

### Candidates define the question

A score can change when a candidate label is renamed or added. Single-label normalization forces competition, whereas multi-label decisions need separate thresholds and evaluation. Generative classification adds another contract: the response must be parsed into a valid label. A pretrained NLI or instruction model has still learned from external labeled tasks; “zero-shot” describes its use on this local label task, not a training-free model.

## Worked example

Two hypothetical entailment logits [1,2] normalize to [0.269,0.731] over the two labels. They do not say that the model has 73.1% real-world correctness. Adding a third candidate with logit 2 changes the normalization even when the original two logits stay fixed. In the recorded lab, merely changing label-description wording flips 11 of 92 held-out/challenge decisions.

## Implement it

This small mechanism uses Python’s standard library and illustrative values; it does not claim to run a pretrained model. Run `python3 scripts/run-examples.py --id discovery-zero-shot-classification`. The connected workflow below supplies the actual model, data, and evaluation.

{/* example:discovery-zero-shot-classification:start */}

```python
from math import exp

logits = [1.0, 2.0]
weights = [exp(v - max(logits)) for v in logits]
print("two-label relative scores:", [round(v / sum(weights), 3) for v in weights])
three = [exp(v - 2) for v in [1.0, 2.0, 2.0]]
print("with another candidate:", [round(v / sum(three), 3) for v in three])
```

## When to use it

Use zero-shot methods for an initial feasibility study or changing label taxonomy when annotation is limited. Still annotate a representative evaluation set and predeclare candidate descriptions. Compare a few-label supervised head before assuming prompt-based methods are the best operational choice.

## Limits and common mistakes

Wording sensitivity, candidate overlap, domain shift, and unknown prior training all limit interpretation. The recorded NLI model uses an explicit pairwise hypothesis and fixed candidate set; it is not the same algorithm as embedding similarity.

## Check your understanding

<details><summary>Does the highest cosine imply the review entails a label description?</summary><p>No. Cosine is geometric similarity in an embedding space. NLI uses a separately trained pairwise inference model and a different scoring rule.</p></details>

<details><summary>May you pick the wording with best test F1 and report that as untouched test performance?</summary><p>No. That uses the test set for selection. Choose descriptions using training/validation evidence, then evaluate on held-out cases or gather a fresh test set.</p></details>

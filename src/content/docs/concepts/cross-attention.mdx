## Definition and intuition

Cross-attention forms queries from one stream and keys/values from another. In an encoder-decoder model, target-side queries retrieve mixtures of source-side states.

A translation decoder has generated two target tokens but needs information from a three-token source. It should inspect source states without pretending that source and target positions are the same sequence.

## How it works

The query matrix has one row per target position, while key/value matrices have one row per source position. QKᵀ therefore produces a rectangular target-by-source score matrix. Row-wise softmax chooses a source mixture for each target query.

A causal mask usually governs target self-attention. Cross-attention instead needs the appropriate source visibility and padding mask; copying a square target-causal mask onto a rectangular source matrix can remove valid evidence or cause shape errors.

Cross-attention can connect modalities when representations and training support that design. The word “cross” alone does not make any two arbitrary vector spaces compatible. Learned projections, dimensional contracts, and the task objective remain necessary.

### The important distinction

A cross-attention map is not guaranteed to be a word alignment.

## Worked example

Two target queries [1,0] and [0,1] compare with three source keys [1,0], [0,1], [1,1]. The first emphasizes sources matching its first coordinate; the second emphasizes sources matching its second. Both outputs are mixtures of three source values, not newly generated words by themselves.

## When to use it

Use cross-attention for source-conditioned generation or other architectures that query an external representation stream. Connect it to sequence-to-sequence tasks rather than assuming every decoder-only model contains this separate layer.

## Limits and common mistakes

A cross-attention map is not guaranteed to be a word alignment. Ignoring source padding lets filler states enter the mixture. Confusing target/source axes can produce plausible visualizations with the wrong interpretation.

<details><summary>A target has four positions and the source has ten plus two pads.

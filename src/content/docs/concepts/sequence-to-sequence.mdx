## Definition and intuition

A sequence-to-sequence system maps an input sequence to an output sequence, which may have a different length. In an encoder-decoder design, an encoder represents the source and a decoder produces target tokens conditioned on that source.

A translation system receives a complete source sentence but must produce a target sentence whose word order and length can differ. A fixed list of sentence labels cannot express that output contract.

## How it works

A recurrent encoder historically compressed a source into a state that initialized the decoder. Long inputs stressed that bottleneck. Attention let the decoder consult a collection of source states instead of relying only on one fixed summary.

In a transformer encoder-decoder, the encoder builds source states, decoder self-attention is causal over target tokens, and cross-attention uses target-derived queries against source-derived keys/values. The source and target lengths can differ, so cross-attention weights form a target_length × source_length matrix.

Teacher forcing supplies observed target prefixes during training. At inference the decoder must use its own selected tokens. The mismatch can expose accumulated errors; a strong training loss alone does not certify good sequence output. Masks should separately handle source padding and target causality.

### The important distinction

Do not assume “decoder” always means decoder-only.

## Worked example

For a source of three tokens and a target prefix of two, a cross-attention head can have Q shape [2, d_k], K shape [3, d_k], V shape [3, d_v], and output [2, d_v]. Each of the two target queries produces a distribution over the three source positions.

## When to use it

Choose an encoder-decoder when a complete source-to-target transformation is central, such as translation or some summarization tasks. A decoder-only prompt can also implement transformations; compare actual task behavior and input/output costs instead of inferring quality from the architecture name.

## Limits and common mistakes

Do not assume “decoder” always means decoder-only. An encoder-decoder includes a decoder too. Cross-attention should not accidentally use target-side future tokens as source evidence. Returned attention weights are not guaranteed linguistic word alignments.

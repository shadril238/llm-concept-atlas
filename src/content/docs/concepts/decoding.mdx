## Definition and intuition

Decoding is the procedure that turns a model’s output scores into selected tokens and an eventual output sequence. Greedy selection and probabilistic sampling use the same model logits through different decision rules.

A model assigns scores to many possible continuations. You must decide whether to choose the maximum, sample, restrict candidates, or stop. Changing that procedure changes outputs without retraining the model.

## How it works

For temperature T>0, softmax uses exp((logit−max_logit)/T) and normalizes the results. Lower T sharpens a nonuniform distribution; higher T flattens it. Greedy decoding is implemented by argmax; a literal softmax temperature of zero would divide by zero.

Top-k retains the k highest-probability candidates. Top-p retains the smallest sorted prefix whose cumulative probability reaches a threshold, including the crossing token. Renormalize after filtering. If combining top-k and top-p, state the order because it affects the result.

A seeded random draw supports repeatability for a declared implementation. It does not make an answer correct or guarantee byte-identical behavior across devices and library versions. Stop rules such as EOS, token limits, or application constraints belong to the generation contract.

### The important distinction

Do not compare decoding runs while silently changing prompts, weights, or stop budgets.

## Worked example

Logits [2,1,0] at T=1 give about [0.665,0.245,0.090]. With top-p=0.8, the first two candidates are retained because the first alone sums to less than 0.8. Renormalization gives about [0.731,0.269,0]. Top-k=1 instead makes selection deterministic for this example.

## Implement it

Run the small mechanism from the repository root with `python3 scripts/run-examples.py --id foundation-decoding`. Its values are illustrative; it isolates the stated operation rather than pretending to load a trained model.

{/* example:foundation-decoding:start */}

```python
from math import exp

logits = [2.0, 1.0, 0.0]
p = [exp(x - max(logits)) for x in logits]
p = [x / sum(p) for x in p]
kept = [0, 1]
print(
    "top-p .8:",
    [round(p[i] / sum(p[j] for j in kept), 3) if i in kept else 0 for i in range(3)],
)
```

## When to use it

Use greedy decoding when a reproducible local choice is helpful, and sampling when varied candidates are useful. Evaluate task quality and format validity under the chosen settings. Diversity is not a substitute for evidence, and a high-temperature setting cannot repair a missing knowledge source.

## Limits and common mistakes

Do not compare decoding runs while silently changing prompts, weights, or stop budgets. Temperature is not confidence calibration. Filtering after a draw is not equivalent to sampling from the filtered distribution. A fluent or diverse result can still be wrong.

## Definition and intuition

**Decoding** is the rule that turns a language model’s scores for possible next tokens into an actual next token. The same model and prompt can produce different text under different decoding settings. Greedy decoding always chooses the highest-scoring token; sampling draws from a probability distribution.

The model predicts a distribution. The decoding rule determines which path through that distribution the output takes.

## Before you start

Read [generative model](/llm-concept-atlas/concepts/generative-model/), [transformer](/llm-concept-atlas/concepts/transformer/) first; return here when the key terms feel familiar.

## How it works

First, model logits are converted or adjusted to probabilities. Temperature scales logits before softmax: lower values sharpen the distribution, while higher values flatten it. Top-k sampling keeps a fixed number of leading candidates; nucleus (top-p) sampling keeps the smallest leading set whose cumulative probability reaches a threshold. The chosen token is appended, and the process repeats until a stop condition.

These controls change diversity, not factual reliability. For reproducible comparisons, fix a random seed where the library supports it. Different tokenizers and stop markers also affect visible output.

## Worked example

Suppose next-token probabilities are `cat 0.6`, `dog 0.3`, `bird 0.1`. Greedy always picks `cat`. Sampling can choose `dog`; top-k with `k=2` removes `bird` and renormalizes the remaining two. A lower temperature would emphasize `cat` further.

## Implement it

**Setup:** Python 3; no packages or API key needed. Save this as `example.py` and run `python3 example.py`. This is a small teaching model, not a pretrained neural network.

```python
from random import Random
options = ['cat','dog','bird']
weights = [0.6,0.3,0.1]
print('greedy:', options[weights.index(max(weights))])
print('sampled:', Random(7).choices(options, weights=weights)[0])
```

**Expected behavior:** `greedy: cat`; the sampled line is repeatable for this Python version and seed.

The code compares a deterministic maximum with a seeded weighted draw. A real generator computes fresh probabilities after each selected token. The seed helps reproduce a demo, but outputs can differ across libraries and hardware.

## When to use it

- Use greedy or low-variance settings when consistency matters.
- Use sampling when diverse drafts are useful, then evaluate output quality separately.

## Limits and common mistakes

- High temperature does not make a model more creative in a guaranteed or uniformly useful way.
- Sampling cannot fix missing evidence; RAG or verification may be needed.

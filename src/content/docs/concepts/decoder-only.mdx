## Definition and intuition

A decoder-only language model uses causally masked transformer blocks to predict continuations from a prefix. At position i it can use permitted positions up to i, and its output predicts the token after that position.

You want a model to continue a sentence one token at a time. Training should not let it inspect the answer token before predicting that answer, so the attention pattern must respect the causal direction.

## How it works

During training, a full observed sequence can be processed in parallel with a causal mask. Each position predicts its next token, and labels are shifted according to the library’s loss contract. Parallel computation over known positions is compatible with a causal learning objective.

At generation time, the future continuation is unknown. The application selects one next token, appends it, then asks for another distribution. This sequential dependency remains even if each forward pass uses parallel tensor operations.

A KV cache stores prior keys and values for each layer so later decode steps avoid rebuilding them. Caching does not remove attention to the prefix, provide unlimited context, or permanently memorize a conversation. Cache positions and masks must match the growing sequence.

### The important distinction

If a supposedly causal mask admits a future position, training loss can improve while actual autoregressive performance fails.

## Worked example

For IDs [A, B, C], outputs at A, B, and C predict B, C, and a possible next token respectively. The triangular mask lets the second position use A and B, but not C. Our real cache lab compares the same forced continuations with and without stored keys/values.

## When to use it

Choose a causal decoder for continuation and many instruction-generation workloads. Use the model’s documented formatting and stop conditions. A base decoder is useful for learning mechanics but may require adaptation and evaluation for a conversational product.

## Limits and common mistakes

If a supposedly causal mask admits a future position, training loss can improve while actual autoregressive performance fails. A generated answer can also repeat or fabricate content even when the causal mechanics are perfectly correct.

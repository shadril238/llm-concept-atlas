## Definition and intuition

**Word2vec** names two related training approaches, skip-gram and continuous bag of words (CBOW), that learn a vector for each word from neighboring-word patterns. It helped show that useful geometric relationships can emerge from a prediction task over text.

Its key limitation is also instructive: a word usually has one learned vector no matter which sentence it appears in. “Bank” beside a river and “bank” beside a loan share the same static row.

## Before you start

Read [token embedding](/llm-concept-atlas/concepts/token-embedding/) first; return here when the key terms feel familiar.

## How it works

In skip-gram, the center word is used to predict surrounding words within a context window. In CBOW, surrounding words help predict the center. Training adjusts word vectors so observed combinations score better than alternatives; negative sampling is one efficient way to provide contrasting examples.

The context window changes what “similar” means. Narrow windows emphasize local syntactic behavior; wider windows can reflect broader topics. The trained table can initialize or inform other tasks, but it does not read a new sentence and change a word vector using that sentence the way a contextual encoder does.

## Worked example

In “the cat chased the mouse,” skip-gram can treat `chased` as the center and `cat` and `mouse` as nearby targets. Repeated examples encourage words with similar contexts to receive related vectors. The training signal is co-occurrence, not a hand-labeled definition.

## Implement it

**Setup:** Python 3; no packages or API key needed. Save this as `example.py` and run `python3 example.py`. This is a small teaching model, not a pretrained neural network.

```python
sentence = 'the cat chased the mouse'.split()
window = 1
pairs = [(sentence[i], sentence[j])
         for i in range(len(sentence))
         for j in range(max(0,i-window), min(len(sentence),i+window+1))
         if i != j]
print(pairs[:4])
```

**Expected behavior:** A list of center/context word pairs, beginning with neighbors of `the` and `cat`.

The code constructs training pairs only; it does not fit vectors. A real word2vec implementation adds an objective, negative examples, and optimization. These pairs show what supervision can come from raw text.

## When to use it

- Word2vec is useful for learning why vector geometry can reflect usage patterns.
- Prefer contextual encoders for polysemy and most current sentence-level tasks.

## Limits and common mistakes

- Similar contexts do not imply identical meaning; antonyms can occur in similar positions.
- Static vectors cannot distinguish multiple senses of the same word in new sentences.

## Definition and intuition

Word2vec learns word representations from local co-occurrence patterns. In skip-gram training, a center item is used to predict nearby context items; negative sampling provides an efficient binary discrimination objective.

You want a vector space in which words that occur in similar contexts have related representations. Counting all vocabulary outputs for every pair is expensive, so training can contrast observed center/context pairs with sampled alternatives.

## How it works

A context window creates positive pairs. For “the cat sleeps” with radius one, pairs include (cat, the) and (cat, sleeps), but not a self-pair at the same position. Window size changes the training signal: local syntax and broader topical co-occurrence need not produce identical neighborhoods.

Skip-gram negative sampling uses separate input and context tables. For center vector u, observed context v+, and sampled negatives v−, minimize softplus(−u·v+) plus the sum of softplus(u·v−). An optimizer changes those learned vectors; constructing pairs alone is not training.

The negative distribution commonly emphasizes frequent items with a smoothed frequency rule. A sampled negative is not a logically false statement, and it can accidentally be a plausible context. Static vectors assign one row to a word, so polysemy and corpus biases remain.

### The important distinction

A nearest neighbor can be an antonym because antonyms occur in similar contexts.

## Worked example

With u=[1,0], v+=[1,0], and v−=[0,1], the positive dot product is 1 and the negative dot product is 0. Their softplus losses are about 0.313 and 0.693, totaling 1.006. Increasing the positive score and decreasing the negative score lowers this objective.

## Implement it

Run the small mechanism from the repository root with `python3 scripts/run-examples.py --id foundation-word2vec`. Its values are illustrative; it isolates the stated operation rather than pretending to load a trained model.

{/* example:foundation-word2vec:start */}

```python
items = "the cat sleeps".split()
pairs = [
    (items[i], items[j])
    for i in range(len(items))
    for j in range(max(0, i - 1), min(len(items), i + 2))
    if i != j
]
print(pairs)
```

## When to use it

Use static vectors as a compact baseline and inspect neighbors before using them as task features. The playlist lab applies the same learned co-occurrence principle to song IDs, while L03 loads actual pretrained GloVe rows for static-word inspection. GloVe is a different training method from Word2vec; sharing a vector interface does not make their objectives identical.

## Limits and common mistakes

A nearest neighbor can be an antonym because antonyms occur in similar contexts. Word2vec does not verify facts or provide sentence-level reasoning. No-interaction or out-of-vocabulary items need a fallback rather than a meaningful-looking random row.

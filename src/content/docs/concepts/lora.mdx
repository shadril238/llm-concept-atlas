## Definition and intuition

LoRA adapts a large weight matrix with a trainable low-rank update while keeping the base matrix fixed.

Chapter 12 distinguishes pretraining, instruction tuning, and preference optimization. Efficient adapters change a subset of parameters; evaluation still decides whether behavior improved.

## Before you start

Read [PEFT](/llm-concept-atlas/concepts/peft/) first. You should be able to explain what information its output carries. Then return here and ask what extra problem **LoRA** solves. This sequence matters because a plausible output can hide a missing prerequisite or a weak input representation.

## Theory: how it works

1. **Prepare:** Select target matrices and a small rank
2. **Transform:** Train two narrow matrices whose product forms the update
3. **Inspect:** Merge or apply the update during inference and evaluate behavior.

### The important distinction

For a weight matrix W, LoRA learns an update ΔW = BA where B and A have a small inner rank r. The number of trainable values scales with r times the input and output widths instead of their product. Rank and target-module choice control how much behavior the adapter can change.

## Worked example

A 2-by-2 toy weight matrix gains a rank-one update from a column times a row. In a real model, the update can be far smaller than the frozen base matrix. Walk through the three stages above with that input: identify what is prepared, what changes, and which observation would show success. Then change one condition in the example. ## Implement it

**Setup:** Python 3; no packages or API key are needed. Save the following as `example.py` and run `python3 example.py`. It is a small deterministic illustration of the relevant calculation or data flow. It does not download a trained model.

```python
base = [[1.0, 0.0], [0.0, 1.0]]
a = [[0.1], [0.2]]
b = [[0.3, -0.1]]
adapted = [[round(base[i][j] + a[i][0]*b[0][j], 3) for j in range(2)] for i in range(2)]
print(adapted)
```

**Expected output:**

```text
[[1.03, -0.01], [0.06, 0.98]]
```

**What the code shows:** The nested list comprehension adds a rank-one outer product to a frozen 2-by-2 matrix. For wider matrices, the small inner rank is what saves trainable parameters. ## Limits and common mistakes

- Rank, target modules, and scaling affect capacity and quality.
- **Failure to look for:** Only one poorly chosen module is adapted, so the desired behavior barely changes despite a low training loss.

A teaching demo usually holds data and model behavior fixed so one mechanism is visible. Real systems face noisy inputs, changing distributions, and edge cases. Test examples that should fail as well as examples that should succeed, and inspect the intermediate stage that causes the error.

## Definition and intuition

A transformer is a neural architecture built around attention and position-wise transformations, usually organized into repeated blocks. Different encoder, decoder, and encoder-decoder variants impose different visibility and output contracts.

You need to trace a model beyond “text goes in, text comes out.” A useful mental model identifies the tokenizer, embedding table, blocks, output head, and external generation loop as separate parts.

## How it works

The tokenizer returns IDs and masks. An embedding lookup creates token vectors. Each block combines attention-based information mixing with position-wise nonlinear computation and residual paths. A final task head maps states to vocabulary logits, class logits, or another output.

For a causal generator with batch B, sequence T, hidden width d, and vocabulary V, input IDs have [B,T], states [B,T,d], and LM logits [B,T,V]. The head’s raw outputs are logits; softmax and token selection are additional operations. A head need not directly return probabilities.

The original transformer was an encoder-decoder architecture. Modern “transformer LLM” often refers to a decoder-only system, but architecture details such as normalization placement, activation, attention sharing, and positional scheme vary. Inspect the actual modules instead of treating one diagram as universal.

### The important distinction

An attention heatmap is only one intermediate tensor, not the model’s complete explanation.

## When to use it

Use the transparent implementation to debug shapes and causal invariants, then inspect a supported trained model for real representations and generation. Random weights can validate mechanics but cannot establish learned language ability or useful task performance.

## Limits and common mistakes

An attention heatmap is only one intermediate tensor, not the model’s complete explanation. Available input positions can be processed in parallel, while unknown output tokens still require sequential selection. Model-specific implementation changes can alter costs without changing this distinction.

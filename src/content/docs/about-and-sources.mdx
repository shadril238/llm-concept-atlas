**LLM Concept Atlas** is an independent, open-source learning companion to *Hands-On Large Language Models* by Jay Alammar and Maarten Grootendorst. It is not affiliated with the authors, O’Reilly Media, or the publisher. The lessons, diagrams, simulations, and examples on this site are original. The book’s PDF, text, and artwork are not included in this repository.

## What is covered now

The atlas has full lessons for its first 20 concepts from chapters 1–3 and 8. The remaining chapter pages outline future coverage; they are not presented as completed concept lessons. Start with [how an LLM processes a sentence](/llm-concept-atlas/paths/how-an-llm-processes-a-sentence/) or [from semantic search to RAG](/llm-concept-atlas/paths/from-semantic-search-to-rag/), then use the [concept graph](/llm-concept-atlas/atlas/) to follow connections.

The browser labs are deliberately small and deterministic. They expose a calculation or decision step; they are **not** the output of a trained model. Pages that require actual model behavior include runnable Python code or links to the authors’ notebooks, and distinguish that code from the teaching simulations.

## Primary sources and further reading

- [*Hands-On Large Language Models* official notebooks](https://github.com/HandsOnLLM/Hands-On-Large-Language-Models) — the authors’ code organized by book chapter.
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — the original Transformer paper.
- [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401) — the original RAG paper.
- [Hugging Face Transformers documentation](https://huggingface.co/docs/transformers/) — tokenizer, model, pipeline, and generation APIs used in examples.
- [Sentence Transformers documentation](https://www.sbert.net/) — sentence embeddings and semantic search used in retrieval examples.

Each concept lesson links its relevant book chapter notebook and a primary technical reference near the end. The code examples may need a current Python environment and can download model weights on first run. Check each model’s license and model card when adapting an example to your own use.

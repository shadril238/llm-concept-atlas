## Set up

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), clone the repository, and run these commands from its root. `uv sync --locked` installs the exact resolved environment.

```bash
uv sync --locked --project examples/foundations
uv sync --locked --project examples/applications
python3 scripts/run-examples.py --id attention-softmax
python3 scripts/run-examples.py --id embedding-retrieval --allow-network
```

The model is Apache-2.0 licensed. It is the 3-layer `sentence-transformers/paraphrase-MiniLM-L3-v2` checkpoint, with its exact revision recorded below. Its small fixture tests inference and ranking, with no training or quality benchmark claim.

## Predict before running

For scores 2 and 1, should the first value receive more than half the weight? For the query “A kitten is resting on a couch”, predict which of the three document sentences will rank first.

## Trace the calculation

```python
from math import exp, isclose, isfinite


def attend(scores: list[float], values: list[float]) -> tuple[list[float], float]:
    if not scores or len(scores) != len(values):
        raise ValueError("Provide equal nonempty score and value lists")
    if not all(isfinite(x) for x in scores + values):
        raise ValueError("Scores and values must be finite")
    # Subtracting the maximum preserves softmax and prevents overflow.
    shifted = [exp(score - max(scores)) for score in scores]
    weights = [value / sum(shifted) for value in shifted]
    return weights, sum(weight * value for weight, value in zip(weights, values))


def main() -> None:
    weights, output = attend([2.0, 1.0], [10.0, 0.0])
    assert isclose(sum(weights), 1.0)
    assert isclose(output, 7.3105857863, abs_tol=1e-9)
    shifted_weights, _ = attend([1002.0, 1001.0], [10.0, 0.0])
    assert all(isclose(a, b) for a, b in zip(weights, shifted_weights))
    print("weights:", [round(weight, 4) for weight in weights])
    print("weighted value:", round(output, 4))


if __name__ == "__main__":
    main()
```

## Run the pretrained model

```python
import json
import os
from pathlib import Path

import numpy as np
import torch
from transformers import AutoModel, AutoTokenizer

MODEL_ID = "sentence-transformers/paraphrase-MiniLM-L3-v2"
REVISION = "4ca70771034acceecb2e72475f72050fcdde4ddc"
ROOT = Path(__file__).resolve().parents[4]


def main() -> None:
    torch.manual_seed(0)
    torch.set_num_threads(1)
    # A local snapshot can be supplied for a fully offline rerun.
    location = os.environ.get("ATLAS_MODEL_PATH", MODEL_ID)
    tokenizer = AutoTokenizer.from_pretrained(location, revision=REVISION)
    model = AutoModel.from_pretrained(location, revision=REVISION).eval().to("cpu")
    data = json.loads((ROOT / "examples/data/fixtures/retrieval.json").read_text())
    texts = [row["text"] for row in data["documents"] + data["queries"]]
    encoded = tokenizer(texts, padding=True, truncation=True, max_length=128, return_tensors="pt")
    with torch.inference_mode():
        hidden = model(**encoded).last_hidden_state  # [5, sequence length, 384]
        mask = encoded["attention_mask"].unsqueeze(-1)
        pooled = (hidden * mask).sum(dim=1) / mask.sum(dim=1).clamp(min=1)
        vectors = torch.nn.functional.normalize(pooled, p=2, dim=1).numpy()
    assert vectors.shape == (5, 384) and np.isfinite(vectors).all()
    assert np.allclose(np.linalg.norm(vectors, axis=1), 1.0, atol=1e-5)
    scores = vectors[3:] @ vectors[:3].T
    rankings = [data["documents"][int(index)]["id"] for index in scores.argmax(axis=1)]
    expected = [query["relevant"] for query in data["queries"]]
    assert rankings == expected, (rankings, expected)
    artifact = Path(os.environ.get("ATLAS_ARTIFACT_DIR", str(ROOT / "examples/artifacts/retrieval")))
    artifact.mkdir(parents=True, exist_ok=True)
    np.save(artifact / "embeddings.npy", vectors)
    assert np.allclose(np.load(artifact / "embeddings.npy"), vectors)
    print(json.dumps({"shape": list(vectors.shape), "top_documents": rankings,
                      "cosine_scores": [[round(float(value), 4) for value in row] for row in scores],
                      "fixture_hits": len(rankings), "fixture_queries": len(expected)}))


if __name__ == "__main__":
    main()
```

## Interpret and investigate

Attention uses invented scores to isolate normalization; the transformer normally learns projections that produce these scores. Adding the same constant to both scores preserves the weights. Try scores 1002 and 1001 and explain why subtracting the maximum avoids overflow.

The model converts token vectors into sentence vectors by averaging only positions allowed by the padding mask, then normalizes each vector. The dot product of normalized vectors is cosine similarity. It is a ranking score, not a probability. The run saves and reloads `embeddings.npy` as an artifact check.

The five authored sentences form a demonstration fixture. The two correct rankings show that the wiring works for these cases. Add an ambiguous query and inspect all scores; this fixture cannot establish general retrieval quality.

## Troubleshoot and continue

A first model download needs internet access and roughly 70 MB of model weights plus tokenizer files. Package installation also downloads PyTorch. No account or API key is required. Later runs can use the cached snapshot with `--offline`; a missing cache causes a recorded failure. See the [example guide](https://github.com/shadril238/llm-concept-atlas/blob/main/examples/README.md) for environments, records, and troubleshooting.

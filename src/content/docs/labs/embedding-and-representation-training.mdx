## Data and evaluation contract

The original MIT intent corpus has 24 training, 12 validation, 18 test and 24 separate unlabeled training-pool sentences across six services. Exact sentence text and IDs are disjoint across splits; the intent categories recur by design. Gold same-intent/different-intent labels define a binary service relation, not NLI classes or human-rated STS. The silver candidate pool never contains validation/test sentences; latent intent is diagnostic only after teacher prediction. These hand-authored domain phrases do not establish general semantic competence.

Classification reuses E4's licensed UCI movie-review fixture: 200 training, 40 validation and 80 test reviews, plus unused challenge probes. Three fixed seeds select eight training reviews per class for every L18 method. The existing validation set has its own annotation cost. The E4 test data were previously published; here they remain excluded from fitting, continued pretraining, silver generation and checkpoint/hyperparameter selection. Fresh external data are needed for new independent generalization claims. Model pretraining overlap is unknown.

NER reuses the original E2 annotation policy, disjoint name sets and 26/6/8 split. Its shared templates make it a controlled transfer example. First-subtoken supervision is the trained route; all-subtoken propagation is a separate actual-tokenizer alignment alternative.

A loss decrease, plausible reconstruction, valid tensor or successful save is not sufficient task success. Author execution/review is separate from independent technical/editorial acceptance and beginner feedback, which remain pending.

## L15 embedding training

Compare the unmodified shared encoder against actual pair-softmax, cosine-regression and MNR training. All start from pretrained tiny BERT; this is a new sentence objective, not language-model training from random weights. The optimizer includes the pair classifier where applicable. MNR batches have one positive pair per distinct intent, preventing the fixture's same-intent alternatives becoming false negatives.

```python
"""L15: real sentence-transformer losses, parameter updates and held-out embedding quality."""

from pathlib import Path
import json
import sys

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
from atlas_representation.common import (
    META,
    MODEL,
    ROOT,
    artifact_files,
    cls_eval,
    encoder,
    fixture,
    losses,
    pairs,
    retrieval_eval,
    save,
    seed,
    similarity_eval,
    torch,
    train_embedding,
)
from atlas_foundations.e7.contracts import cross_entropy, mnr_loss
from sklearn.decomposition import PCA


def main():
    seed()
    data = fixture()
    gold = pairs(data, "train")
    val = pairs(data, "validation")
    test = pairs(data, "test")
    baseline = encoder()
    base = dict(
        similarity=similarity_eval(baseline, test),
        retrieval=retrieval_eval(baseline, data, "test"),
    )
    view_rows = [r for r in data["rows"] if r["split"] == "test"]
    fit_texts = [r["text"] for r in data["rows"] if r["split"] == "train"]
    pca = PCA(n_components=2).fit(baseline.encode(fit_texts, normalize_embeddings=True))
    base_points = pca.transform(
        baseline.encode([r["text"] for r in view_rows], normalize_embeddings=True)
    )
    results = []
    checks = {}
    for kind in ["softmax", "cosine", "mnr"]:
        model = encoder()
        objective = (
            losses.SoftmaxLoss(model, 128, 2)
            if kind == "softmax"
            else losses.CosineSimilarityLoss(model)
            if kind == "cosine"
            else losses.MultipleNegativesRankingLoss(model, scale=20)
        )
        selected = gold if kind != "mnr" else [r for r in gold if r["label"] == 1]
        probe = (
            selected[:4]
            if kind != "mnr"
            else [
                next(r for r in selected if r["left_id"].split("-")[1] == i)
                for i in sorted({r["intent"] for r in data["rows"]})
            ]
        )
        model.eval()
        objective.eval()
        features = [model.tokenize([r[k] for r in probe]) for k in ["left", "right"]]
        with torch.no_grad():
            if kind == "softmax":
                reps, logits = objective(features, None)
                target = int(probe[0]["label"])
                checks[kind] = dict(
                    concatenated_width=3 * 128,
                    logits=logits[0].tolist(),
                    target=target,
                    manual=cross_entropy(logits[0].tolist(), target),
                    library=float(
                        torch.nn.functional.cross_entropy(
                            logits[:1], torch.tensor([target])
                        )
                    ),
                )
            elif kind == "cosine":
                u = model(features[0])["sentence_embedding"]
                v = model(features[1])["sentence_embedding"]
                cos = torch.nn.functional.cosine_similarity(u, v)
                targets = torch.tensor([r["label"] for r in probe])
                checks[kind] = dict(
                    scores=cos.tolist(),
                    targets=targets.tolist(),
                    manual=float(((cos - targets) ** 2).mean()),
                    library=float(
                        objective(
                            [
                                model.tokenize([r[k] for r in probe])
                                for k in ["left", "right"]
                            ],
                            targets,
                        )
                    ),
                )
            else:
                u = torch.nn.functional.normalize(
                    model(features[0])["sentence_embedding"], dim=-1
                )
                v = torch.nn.functional.normalize(
                    model(features[1])["sentence_embedding"], dim=-1
                )
                scores = (u @ v.T).tolist()
                checks[kind] = dict(
                    scores=scores,
                    scale=20,
                    manual=mnr_loss(scores)["loss"],
                    library=float(
                        torch.nn.functional.cross_entropy(
                            torch.tensor(scores) * 20, torch.arange(len(scores))
                        )
                    ),
                )
        assert abs(checks[kind]["manual"] - checks[kind]["library"]) < 2e-5
        directory = ROOT / f"examples/artifacts/e7-embedding/{kind}"
        training = train_embedding(
            model, objective, data, selected, directory=directory, kind=kind
        )
        result = dict(
            kind=kind,
            training=training,
            similarity=similarity_eval(model, test),
            retrieval=retrieval_eval(model, data, "test"),
            artifact=artifact_files(directory),
        )
        if kind == "softmax":
            objective.eval()
            with torch.no_grad():
                reps, logits = objective(
                    [model.tokenize([r[k] for r in test]) for k in ["left", "right"]],
                    None,
                )
            result["pair_classification"] = cls_eval(
                [int(r["label"]) for r in test], logits.argmax(-1).tolist()
            )
        points = pca.transform(
            model.encode([r["text"] for r in view_rows], normalize_embeddings=True)
        )
        result["projection"] = [
            dict(
                id=r["id"],
                text=r["text"],
                intent=r["intent"],
                before=a.tolist(),
                after=b.tolist(),
            )
            for r, a, b in zip(view_rows, base_points, points)
        ]
        results.append(result)
    save(
        "e7-embedding",
        dict(
            model=META[MODEL],
            baseline=base,
            conditions=results,
            loss_checks=checks,
            projection_policy="One PCA fitted to baseline training vectors, then frozen for test before/after projections. Two displayed dimensions omit information; full 128-D similarities drive evaluation.",
            protocol=data["protocol"],
            verified=True,
        ),
    )
    print(
        json.dumps(
            dict(
                training_updates_verified=True,
                loss_arithmetic_verified=True,
                reload_verified=True,
                conditions=len(results),
            )
        )
    )


if __name__ == "__main__":
    main()
```

## L16 Augmented SBERT

Train the cross-encoder teacher on gold training pairs, select it on gold validation, generate 120 continuous silver probabilities from a separate training-only pool, and train gold-only/gold-plus-silver students from the same initialization. This includes genuine teacher training, not an inference-only shortcut. Candidate generation does not use the pool's latent intent labels.

<SilverExplorer client:visible />

The first author run contains fourteen thresholded teacher disagreements; the continuous values, not thresholded diagnostics, train the student. Adding silver worsens held-out pair MSE in this small run. Both students have sixty optimizer steps, but the mixture changes gold exposure and sampled examples. More data and a competent teacher are not sufficient to guarantee better geometry.

```python
"""L16: train a cross-encoder teacher, label training-only pairs, compare two students."""

from pathlib import Path
import json
import sys

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
from atlas_representation.common import (
    AutoModelForSequenceClassification,
    AutoTokenizer,
    MODEL,
    ROOT,
    artifact_files,
    cls_eval,
    copy,
    download,
    encoder,
    fixture,
    losses,
    pairs,
    random,
    retrieval_eval,
    save,
    seed,
    similarity_eval,
    state_hash,
    torch,
    train_embedding,
)


def main():
    seed()
    data = fixture()
    gold = pairs(data, "train")
    valid = pairs(data, "validation")
    test = pairs(data, "test")
    by = {r["id"]: r for r in data["rows"]}
    tokenizer = AutoTokenizer.from_pretrained(download(MODEL), local_files_only=True)
    teacher = AutoModelForSequenceClassification.from_pretrained(
        download(MODEL), num_labels=2, local_files_only=True
    ).cpu()
    initial = state_hash(teacher)
    optimizer = torch.optim.AdamW(teacher.parameters(), lr=3e-4, weight_decay=0.01)
    history = []
    best = None
    score = None
    gradient = None
    rng = random.Random(42)

    def predict(rows):
        teacher.eval()
        with torch.no_grad():
            return teacher(
                **tokenizer(
                    [r["left"] for r in rows],
                    [r["right"] for r in rows],
                    padding=True,
                    truncation=True,
                    max_length=64,
                    return_tensors="pt",
                )
            ).logits.softmax(-1)[:, 1]

    for step in range(60):
        batch = rng.sample(gold, 8)
        teacher.train()
        optimizer.zero_grad()
        inputs = tokenizer(
            [r["left"] for r in batch],
            [r["right"] for r in batch],
            padding=True,
            truncation=True,
            max_length=64,
            return_tensors="pt",
        )
        labels = torch.tensor([int(r["label"]) for r in batch])
        loss = teacher(**inputs, labels=labels).loss
        loss.backward()
        if step == 0:
            gradient = float(
                teacher.bert.encoder.layer[0].attention.self.query.weight.grad.norm()
            )
        torch.nn.utils.clip_grad_norm_(teacher.parameters(), 1)
        optimizer.step()
        if (step + 1) % 10 == 0:
            probs = predict(valid)
            labels = torch.tensor([r["label"] for r in valid])
            value = float(torch.nn.functional.binary_cross_entropy(probs, labels))
            history.append(
                dict(
                    step=step + 1, loss=float(loss.detach()), validation_binary_ce=value
                )
            )
            if score is None or value < score:
                score = value
                best = copy.deepcopy(teacher.state_dict())
                best_step = step + 1
    teacher.load_state_dict(best)
    assert state_hash(teacher) != initial and gradient > 0
    folder = ROOT / "examples/artifacts/e7-augmentation/teacher"
    teacher.save_pretrained(folder)
    tokenizer.save_pretrained(folder)
    before = predict(valid)
    reloaded = AutoModelForSequenceClassification.from_pretrained(folder).eval()
    with torch.no_grad():
        after = reloaded(
            **tokenizer(
                [r["left"] for r in valid],
                [r["right"] for r in valid],
                padding=True,
                truncation=True,
                max_length=64,
                return_tensors="pt",
            )
        ).logits.softmax(-1)[:, 1]
    assert torch.allclose(before, after, atol=1e-6)
    candidates = [
        dict(p, left=by[p["left_id"]]["text"], right=by[p["right_id"]]["text"])
        for p in data["silver_candidates"]
    ]
    scores = predict(candidates).tolist()
    silver = [
        dict(p, label=float(value), origin="trained teacher probability, not gold")
        for p, value in zip(candidates, scores)
    ]
    # Hidden fixture intents are used after prediction for diagnostics only, never teacher targets.
    diagnostics = [
        dict(
            id=p["id"],
            teacher_score=p["label"],
            latent_same_intent=by[p["left_id"]]["intent"]
            == by[p["right_id"]]["intent"],
            disagreement=(p["label"] >= 0.5)
            != (by[p["left_id"]]["intent"] == by[p["right_id"]]["intent"]),
        )
        for p in silver
    ]
    students = []
    base = encoder()
    baseline = similarity_eval(base, test)
    for kind, rows in [("gold-only", gold), ("gold-plus-silver", gold + silver)]:
        model = encoder()
        objective = losses.CosineSimilarityLoss(model)
        path = ROOT / f"examples/artifacts/e7-augmentation/{kind}"
        training = train_embedding(
            model, objective, data, rows, steps=60, directory=path
        )
        students.append(
            dict(
                condition=kind,
                training=training,
                similarity=similarity_eval(model, test),
                retrieval=retrieval_eval(model, data, "test"),
                train_pairs=len(rows),
                artifact=artifact_files(path),
            )
        )
    result = dict(
        teacher=dict(
            history=history,
            selected_step=best_step,
            initial_sha256=initial,
            selected_sha256=state_hash(teacher),
            first_query_gradient_norm=gradient,
            validation_scores=before.tolist(),
            test=cls_eval(
                [int(r["label"]) for r in test], [int(x >= 0.5) for x in predict(test)]
            ),
            artifact=artifact_files(folder),
        ),
        baseline=baseline,
        students=students,
        silver=silver,
        diagnostics=diagnostics,
        protocol=data["protocol"],
        comparison_limit="Equal 60-step student budgets and initialization; adding silver changes pair distribution and exposure, not only label quality. Teacher errors remain visible; no independent benchmark claim.",
        verified=True,
    )
    save("e7-augmentation", result)
    print(
        json.dumps(
            dict(
                teacher_trained=True,
                silver_split_verified=True,
                students_updated=True,
                reload_verified=True,
                silver_pairs=len(silver),
            )
        )
    )


if __name__ == "__main__":
    main()
```

## L17 TSDAE and adaptation

Actual Sentence Transformers denoising loss encodes damaged training text into one CLS vector and conditions a causal decoder on it. Compatible encoder/decoder parameters are tied; newly initialized cross-attention value/output paths learn. With a single context key, the attention softmax is always one, so query/key selection gradients may be zero. The checks verify the actual value gradient and updated bridge instead of requiring impossible nonzero gradients everywhere.

<DenoisingExplorer client:visible />

The source compares baseline CLS embeddings, selected TSDAE-only embeddings, gold-only regression and TSDAE-plus-gold adaptation. It preserves actual repetitive greedy reconstruction and training-loss intervals without retrieval improvement. Gold previous tokens make teacher-forced outputs a different test from free reconstruction. Right padding is excluded from the pinned reconstruction loss; CLS pooling is a declared experiment choice, not a claim that contextual mean pooling removes all position information.

```python
"""L17: actual tied TSDAE reconstruction, retrieval checks and supervised adaptation."""

from pathlib import Path
import json
import sys

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
from atlas_representation.common import (
    ROOT,
    SentenceTransformer,
    artifact_files,
    copy,
    encoder,
    fixture,
    losses,
    np,
    pairs,
    random,
    retrieval_eval,
    save,
    seed,
    similarity_eval,
    state_hash,
    torch,
    train_embedding,
)
from atlas_foundations.e7.contracts import delete_words


def main():
    seed()
    data = fixture()
    texts = [r for r in data["rows"] if r["split"] == "train"]
    by_id = {r["id"]: r for r in texts}
    damaged = [
        dict(id=r["id"], **delete_words(r["text"], 42 + i)) for i, r in enumerate(texts)
    ]
    model = encoder("cls")
    baseline = dict(
        similarity=similarity_eval(model, pairs(data, "test")),
        retrieval=retrieval_eval(model, data, "test"),
    )
    initial = state_hash(model)
    objective = losses.DenoisingAutoEncoderLoss(model, tie_encoder_decoder=True).cpu()
    tokenizer = objective.tokenizer_decoder
    assert (
        model[0].auto_model.embeddings.word_embeddings.weight.data_ptr()
        == objective.decoder.bert.embeddings.word_embeddings.weight.data_ptr()
    )
    optimizer = torch.optim.AdamW(objective.parameters(), lr=1e-4, weight_decay=0.01)
    rng = random.Random(42)
    history = []
    gradients = {}
    best = None
    best_score = None

    def reconstruction_loss():
        objective.eval()
        values = []
        with torch.no_grad():
            for start in range(0, len(damaged), 4):
                batch = damaged[start : start + 4]
                features = [
                    model.tokenize([r[k] for r in batch])
                    for k in ["damaged", "original"]
                ]
                values.append(float(objective(features, None)))
        return sum(values) / len(values)

    decoder_initial = state_hash(objective.decoder, lambda n, p: "crossattention" in n)
    original_loss = reconstruction_loss()
    initial_retrieval = retrieval_eval(model, data, "validation")
    history.append(
        dict(
            step=0,
            reconstruction_training_probe_loss=original_loss,
            validation_mrr=initial_retrieval["mrr"],
        )
    )
    for step in range(60):
        batch = rng.sample(damaged, 4)
        objective.train()
        optimizer.zero_grad()
        features = [
            model.tokenize([r[k] for r in batch]) for k in ["damaged", "original"]
        ]
        loss = objective(features, None)
        assert torch.isfinite(loss)
        loss.backward()
        if step == 0:
            decoder_first_gradient = float(
                objective.decoder.bert.encoder.layer[
                    0
                ].crossattention.self.value.weight.grad.norm()
            )
            decoder_query_gradient = float(
                objective.decoder.bert.encoder.layer[
                    0
                ].crossattention.self.query.weight.grad.norm()
            )
            gradients = {
                n: float(p.grad.norm())
                for n, p in model.named_parameters()
                if p.grad is not None
            }
        torch.nn.utils.clip_grad_norm_(objective.parameters(), 1)
        optimizer.step()
        if (step + 1) % 10 == 0:
            value = reconstruction_loss()
            quality = retrieval_eval(model, data, "validation")
            history.append(
                dict(
                    step=step + 1,
                    reconstruction_training_probe_loss=value,
                    validation_mrr=quality["mrr"],
                )
            )
            # Match the deployed encoder's task, not the reconstruction surrogate alone.
            criterion = quality["mrr"]
            if best_score is None or criterion > best_score:
                best_score = criterion
                best = copy.deepcopy(objective.state_dict())
                best_step = step + 1
    objective.load_state_dict(best)
    assert decoder_first_gradient > 0 and decoder_initial != state_hash(
        objective.decoder, lambda n, p: "crossattention" in n
    )
    model.eval()
    assert state_hash(model) != initial and any(g > 0 for g in gradients.values())
    after_tsdae = dict(
        similarity=similarity_eval(model, pairs(data, "test")),
        retrieval=retrieval_eval(model, data, "test"),
    )
    directory = ROOT / "examples/artifacts/e7-denoising/tsdae"
    model.save_pretrained(directory)
    objective.decoder.save_pretrained(directory / "decoder")
    tokenizer.save_pretrained(directory / "decoder")
    reloaded = SentenceTransformer(str(directory), device="cpu")
    assert np.allclose(
        model.encode([r["text"] for r in texts]),
        reloaded.encode([r["text"] for r in texts]),
        atol=1e-6,
    )
    sample = damaged[0]
    objective.eval()
    with torch.no_grad():
        reps = model(model.tokenize([sample["damaged"]]))["sentence_embedding"]
        generated = objective.decoder.generate(
            input_ids=torch.tensor([[tokenizer.cls_token_id]]),
            encoder_hidden_states=reps[:, None],
            encoder_attention_mask=torch.ones((1, 1), dtype=torch.long),
            max_new_tokens=24,
            do_sample=False,
            eos_token_id=tokenizer.sep_token_id,
            pad_token_id=tokenizer.pad_token_id,
        )
        raw = tokenizer.decode(generated[0], skip_special_tokens=True)
    teacher_forced = model.tokenize([sample["original"]])
    with torch.no_grad():
        ids = teacher_forced["input_ids"]
        out = objective.decoder(
            input_ids=ids[:, :-1],
            encoder_hidden_states=reps[:, None],
            encoder_attention_mask=torch.ones((1, 1), dtype=torch.long),
        )
        pred = out.logits.argmax(-1)[0].tolist()
    conditions = []
    for name, student in [("gold-only", encoder("cls")), ("tsdae-plus-gold", model)]:
        obj = losses.CosineSimilarityLoss(student)
        path = ROOT / f"examples/artifacts/e7-denoising/{name}"
        training = train_embedding(
            student, obj, data, pairs(data, "train"), steps=60, directory=path
        )
        conditions.append(
            dict(
                condition=name,
                training=training,
                similarity=similarity_eval(student, pairs(data, "test")),
                retrieval=retrieval_eval(student, data, "test"),
                artifact=artifact_files(path),
            )
        )
    counterexamples = [
        dict(before=a, after=b)
        for a, b in zip(history, history[1:])
        if b["reconstruction_training_probe_loss"]
        < a["reconstruction_training_probe_loss"]
        and b["validation_mrr"] <= a["validation_mrr"]
    ]
    save(
        "e7-denoising",
        dict(
            baseline=baseline,
            tsdae=after_tsdae,
            history=history,
            selected_step=best_step,
            selection="first maximum validation retrieval MRR, not minimum reconstruction loss",
            corruption=damaged,
            reconstruction=dict(
                source=sample,
                greedy=raw,
                greedy_ids=generated[0].tolist(),
```

```python
import json
```

```python
from transformers import AutoModelForMaskedLM, DataCollatorForLanguageModeling


def main():
    source = sentiment()["rows"]
    train = [r for r in source if r["split"] == "train"]
    valid = [r for r in source if r["split"] == "validation"]
    test = [r for r in source if r["split"] == "test"]
    tokenizer = AutoTokenizer.from_pretrained(download(MODEL), local_files_only=True)
    encode = lambda rows: [
        tokenizer(
            r["text"], truncation=True, max_length=96, return_special_tokens_mask=True
        )
        for r in rows
    ]
    training = encode(train)
    validation = encode(valid)
    collator = DataCollatorForLanguageModeling(
        tokenizer=tokenizer, mlm=True, mlm_probability=0.15, seed=999
    )
    fixed = [collator(validation[i : i + 8]) for i in range(0, len(validation), 8)]
    assert all((b["labels"] != -100).any() for b in fixed)

    def evaluate(model):
        model.eval()
        total = 0.0
        tokens = 0
        with torch.no_grad():
            for b in fixed:
                count = int((b["labels"] != -100).sum())
                total += float(model(**b).loss) * count
                tokens += count
        return total / tokens

    def adapt(steps, name, keep=False):
        seed()
        model = AutoModelForMaskedLM.from_pretrained(
            download(MODEL), local_files_only=True
        ).cpu()
        initial = state_hash(model)
        baseline = evaluate(model)
        optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
        dynamic = DataCollatorForLanguageModeling(
            tokenizer=tokenizer, mlm=True, mlm_probability=0.15, seed=42
        )
        rng = random.Random(42)
        history = []
        best = None
        score = None
        grad = None
        for step in range(steps):
            batch = dynamic(rng.sample(training, 8))
            assert (batch["labels"] != -100).any()
            model.train()
            optimizer.zero_grad()
            loss = model(**batch).loss
            assert torch.isfinite(loss)
            loss.backward()
            if step == 0:
                grad = float(
                    model.bert.encoder.layer[0].attention.self.query.weight.grad.norm()
                )
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1)
            optimizer.step()
            if (step + 1) % 10 == 0 or step == steps - 1:
                value = evaluate(model)
                history.append(
                    dict(
                        step=step + 1,
                        training_loss=float(loss.detach()),
                        validation_masked_loss=value,
                    )
                )
                if score is None or value < score:
                    score = value
                    best = copy.deepcopy(model.state_dict())
                    best_step = step + 1
        model.load_state_dict(best)
        assert state_hash(model) != initial and grad > 0
        directory = ROOT / f"examples/artifacts/e7-mlm/{name}"
        model.save_pretrained(directory)
        tokenizer.save_pretrained(directory)
        reloaded = AutoModelForMaskedLM.from_pretrained(directory).eval()
        assert abs(evaluate(model) - evaluate(reloaded)) < 1e-6
        sentence = "The acting was [MASK]."
        probe = tokenizer(sentence, return_tensors="pt")
        position = int((probe["input_ids"][0] == tokenizer.mask_token_id).nonzero()[0])
        with torch.no_grad():
            probs = reloaded(**probe).logits[0, position].softmax(-1)
            values, ids = probs.topk(5)
        return dict(
            profile=name,
            steps=steps,
            baseline_masked_validation_loss=baseline,
            selected_validation_loss=score,
            selected_step=best_step,
            history=history,
            initial_sha256=initial,
            updated_sha256=state_hash(model),
            first_query_gradient_norm=grad,
            reload_verified=True,
            fill_mask=dict(
                input=sentence,
                top=[
                    dict(
                        token=tokenizer.convert_ids_to_tokens(int(i)),
                        probability=float(v),
                    )
                    for i, v in zip(ids, values)
                ],
            ),
            artifact=artifact_files(directory),
        ), directory

    smoke, _ = adapt(2, "smoke-2-steps")
    evaluated, path = adapt(60, "evaluated-60-steps")
    # Equal downstream data, step budget and random head seed; the adapted encoder is the intended intervention.
    downstream = []
    for name, backbone in [("pretrained", None), ("mlm-adapted", str(path))]:
        directory = ROOT / f"examples/artifacts/e7-mlm/downstream-{name}"
        row = classifier_run(
            train, valid, test, directory, backbone=backbone, run_seed=42, steps=60
        )
        row["condition"] = name
        downstream.append(row)
    assert (
        downstream[0]["head_pooler_initial_sha256"]
        == downstream[1]["head_pooler_initial_sha256"]
    )
    original = tokenizer.pad(validation[:8], padding=True, return_tensors="pt")
    b = fixed[0]
    tokens = []
    for i, (orig, changed, label, mask) in enumerate(
        zip(
            original["input_ids"][0],
            b["input_ids"][0],
            b["labels"][0],
            original["special_tokens_mask"][0],
        )
    ):
        if int(label) != -100:
            assert not int(mask) and int(label) == int(orig)
        tokens.append(
            dict(
                position=i,
                original_id=int(orig),
                input_id=int(changed),
                label=int(label),
                original_token=tokenizer.convert_ids_to_tokens(int(orig)),
                input_token=tokenizer.convert_ids_to_tokens(int(changed)),
                special_or_padding=bool(mask) or int(orig) == tokenizer.pad_token_id,
                loss_included=int(label) != -100,
            )
        )
    save(
        "e7-mlm",
        dict(
            smoke=smoke,
            evaluated=evaluated,
            downstream=downstream,
            mask_trace=tokens,
            training_ids=[r["id"] for r in train],
            validation_ids=[r["id"] for r in valid],
            test_ids=[r["id"] for r in test],
            protocol="Only 200 training review texts enter continued pretraining, never labels/test/challenge texts. Fixed dynamically-created validation masks select minimum validation masked-token loss; 60-step evaluated run is separate from a two-step smoke run. Downstream runs have identical data/seed/budget and validation-only classification selection. Pretraining overlap of the original downloaded checkpoint is unknown.",
            masking="Actual Transformers collator: 15% eligible token selection, nominal 80% mask / 10% random vocabulary / 10% unchanged among selected tokens. Observed unchanged IDs do not identify which random branch produced them. Special/padding labels remain -100.",
            verified=True,

                test_excluded=True,
```

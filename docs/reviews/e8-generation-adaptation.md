## Outcome and limitations

The small author run improves LoRA reference NLL (3.098 baseline to 2.721) but worsens full-fine-tuning NLL (3.210). Reward pair accuracy rises from 3/8 to 6/8. DPO learns authored-pair preference margins while worsening completion perplexity. All four policies have0/8 normalized generated exact matches. These failures remain visible and rule out a production extraction-quality claim from this experiment. Repeatedly reading published test cases is not a new independent benchmark; future tuning needs fresh data.

The interactive loss-mask inspector, rank/memory calculator, actual adaptation results, reward/DPO trace and evaluation disagreement dashboard distinguish calculations from recorded evidence and expose raw values. New lab/project/path pages connect the learning sequence. Graph relationships identify whether an edge supplies data, an update method, a scorer or a validation obligation. Independent reviewers should follow one EOS/pad case, one wrong answer, one merge difference and one preference/task disagreement end to end before acceptance.
